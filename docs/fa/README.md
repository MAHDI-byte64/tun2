# مستندات فارسی

[English](../README.md) · **فارسی**

همهٔ مستندات کاریز به فارسی هم هست. نام تنظیم‌ها، دستورها و مقدارها به انگلیسی می‌ماند، چون همان‌ها را در کانفیگ و ترمینال می‌نویسید. این صفحه‌ها نسخهٔ ۲٫۷٫۰ را شرح می‌دهند؛ تغییرهای هر نسخه در [تغییرات](CHANGELOG.md) آمده است. همین صفحه‌ها با جستجو، نمودارهای متحرک و دموی زندهٔ پنل در وب‌سایت هستند: <https://mahdi-byte64.github.io/tun2/fa/>
